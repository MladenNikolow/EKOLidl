# EKOLidl - Накрая стигам до морето

## 📖 За проекта

**„НАКРАЯ СТИГАМ ДО МОРЕТО"** е проект на Морски клуб "Приятели на морето" - Варна, насочен към борбата със замърсяването на плажовете и морето с пластмасови отпадъци.

### 🎯 Основна цел

Проучванията в световен мащаб показват, че без значение къде се изхвърля боклука, близо 80% от него накрая стига до морето. Заставайки зад каузата "Плажове и море свободни от пластмаса", проектът си поставя за цел чрез атрактивни дейности да формира активна позиция в деца и младежи по отношение на проблема, свързан със замърсяването на плажовете и морето с пластмасови отпадъци и въздействието им върху човека и морската флора и фауна.

### 📋 Дейности по проекта

- **Информационни материали**: Изработване на информационни и образователни материали. Създаване на специална платформа за отразяване на дейностите и регистриране на сигнали за замърсени райони по крайбрежието
- **Фото-лов**: Подаване на сигнали за замърсени крайбрежни райони и нерегламентирани сметища
- **Обучения**: Провеждане на 17 неформални обучения на деца и младежи от Варна, Каварна и Шабла на тема "Накрая стигам до морето"
- **Гмуркане**: Провеждане на обучение по гмуркане на 20 участници в проекта за подводно почистване на определени райони
- **Кампании**: 8 кампании на неохраняеми плажове за почистване от пластмаса от Варна до Шабла
- **Заключително събитие**: По случай 31 октомври - Международен ден на Черно море

### 🎖️ Очаквани резултати

- Формиране на активна позиция по отношение на замърсяването с пластмаса на поне 600 деца и младежи
- Изграждане на нов екип от 20 доброволци, които активно да работят по каузата "Плажове и море свободни от пластмаса"
- Активиране на местните общности и институции по отношение на опазване чистотата на българското крайбрежие

## 🏗️ Техническа информация

### Използвани технологии

- **Framework**: ASP.NET Core 10 MVC (Razor Views)
- **База данни**: Azure Cosmos DB (контейнери `Events` и `Signals`)
- **Снимки**: Azure Blob Storage
- **Хостинг**: Azure App Service (Windows)
- **Code Quality**: StyleCop Analyzers (`Rules.ruleset`, `stylecop.json`, общи настройки в `Directory.Build.props`)

### Архитектура на проекта

```
EKOLidl/
├── Web/
│   ├── EKOLidl.Web/             # ASP.NET Core MVC приложение
│   └── EKOLidl.Web.ViewModels/  # View модели
├── Services/
│   ├── EKOLidl.Services.Data/   # Cosmos DB репозитории, Blob Storage, валидация на снимки
│   └── EKOLidl.Services.Messaging/ # не се използва и не е в решението
├── Data/
│   ├── EKOLidl.Data.Models/     # Модели на данни (Event, Signal, ...)
│   └── EKOLidl.Data.Common/     # Общи интерфейси за данни
└── EKOLidl.Common/              # Общи константи
```

### Основни функционалности

- **Събития**: архив на дейностите по проекта, с албум и резултати
- **Сигнали**: всеки може да подаде сигнал за замърсен район със снимки; сигналът става публичен след одобрение
- **Администраторски панел**: управление на съдържанието

## 🚀 Как да стартираме проекта

### Предварителни изисквания

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Azure Cosmos DB Emulator](https://learn.microsoft.com/azure/cosmos-db/emulator) (локална база данни)
- [Azurite](https://learn.microsoft.com/azure/storage/common/storage-use-azurite) (локално Blob Storage), напр. чрез Node.js: `npx azurite --silent --location .azurite`

### Стъпки

1. Клонирайте репозиторито:
   ```bash
   git clone https://github.com/MladenNikolow/EKOLidl.git
   cd EKOLidl
   ```
2. Стартирайте Cosmos DB Emulator и Azurite.
3. Стартирайте приложението:
   ```bash
   dotnet run --project Web/EKOLidl.Web
   ```
4. Отворете `https://localhost:5001`.

В среда `Development` приложението използва `appsettings.Development.json`, който сочи към двата емулатора. При първо стартиране то създава базата, контейнерите и Blob контейнера и добавя примерни събития и сигнали. Продукционните данни не се използват.

**Работа с реалните данни в Azure** (само при нужда): задайте ключовете чрез User Secrets. Те имат предимство пред `appsettings.Development.json`:
```bash
dotnet user-secrets --project Web/EKOLidl.Web set "AzureConnections:CosmosDB:EndpointUrl" "<endpoint>"
dotnet user-secrets --project Web/EKOLidl.Web set "AzureConnections:CosmosDB:PrimaryKey" "<key>"
```
Не подавайте тестови сигнали срещу продукционната база.

### Администрация

Администрацията е на `/admin`. Там се одобряват, скриват и изтриват сигнали, добавят се резултати и се редактират събития.

- **Локално** (среда `Development`): потребител `admin`, парола `local-dev-admin-2026`. Профилът е само в `appsettings.Development.json` и работи само с емулаторите.
- **В Azure**: задайте `Admin__Username` и `Admin__PasswordHash` в App Service → Configuration. Паролата никога не се пази в явен вид. Хешът се генерира така (паролата е поне 12 символа и не се показва при въвеждане):
  ```bash
  dotnet run --project Web/EKOLidl.Web -- --hash-password
  ```
- Смяната на `Admin__PasswordHash` излиза от всички отворени сесии.
- След 5 неуспешни опита за вход от един IP адрес входът се блокира за 5 минути.

### Конфигурация в Azure

Продукционните настройки са в App Service → Configuration (`AzureConnections__CosmosDB__EndpointUrl`, `AzureConnections__CosmosDB__PrimaryKey`, `AzureConnections__CosmosDB__DatabaseName`, `AzureConnections__CosmosDB__Containers__0__Name` и т.н., `AzureConnections__BlobStorage__ConnectionString`, `AzureConnections__BlobStorage__Container`). Никога не commit-вайте ключове в репозиторито.
