# EKOLidl - Накрая стигам до морето

## 📖 За проекта

**„НАКРАЯ СТИГАМ ДО МОРЕТО"** е проект на Морски клуб "Приятели на морето" - Варна, насочен към борбата със замърсяването на плажовете и морето с пластмасови отпадъци.

### 🎯 Основна цел

Проучванията в световен мащаб показват, че без значение къде се изхвърля боклука, близо 80% от него накрая стига до морето. Заставайки зад каузата "Плажове и море свободни от пластмаса", проектът си поставя за цел чрез атрактивни дейности да формира активна позиция в деца и младежи по отношение на проблема, свързан със замърсяването на плажовете и морето с пластмасови отпадъци и въздействието им върху човека и морската флора и фауна.

### 📋 Дейности по проекта

- **Информационни материали**: Изработване на информационни и образователни материали. Създаване на специална платформа за отразяване на дейностите и регистриране на сигнали за замърсени райони по крайбрежието
- **Фото-лов**: Подаване на сигнали за замърсени крайбрежни райони и нерегламентирани сметища
- **Обучения**: Провеждане на 17 неформални обучения на деца и младежи от Варна, Каварна и Шабла на тема "Накрая стигам до морето"
- **Гмуркане**: Провеждане на обучение по гмуркане на 20 участници в проекта за подводно почистване на определени райони
- **Кампании**: 8 кампании на неохраняеми плажове за почистване от пластмаса от Варна до Шабла
- **Заключително събитие**: По случай 31 октомври - Международен ден на Черно море

### 🎖️ Очаквани резултати

- Формиране на активна позиция по отношение на замърсяването с пластмаса на поне 600 деца и младежи
- Изграждане на нов екип от 20 доброволци, които активно да работят по каузата "Плажове и море свободни от пластмаса"
- Активиране на местните общности и институции по отношение на опазване чистотата на българското крайбрежие

## 🏗️ Техническа информация

### Използвани технологии

- **Framework**: ASP.NET Core 6.0
- **Database**: Microsoft SQL Server with Entity Framework Core 5.0.6
- **Frontend**: 
  - ASP.NET Core MVC (Razor Views)
  - Bootstrap
  - JavaScript/jQuery
- **Authentication**: ASP.NET Core Identity
- **Cloud Storage**: Azure Blob Storage (за съхранение на изображения)
- **Email**: SendGrid (за имейл услуги)
- **Code Quality**: StyleCop Analyzers

## 🚀 Как да стартираме проекта

### Предварителни изисквания

- .NET 6.0 SDK
- SQL Server (LocalDB или пълна версия)
- Visual Studio 2022 или Visual Studio Code
- Azure Storage Account (за работа с изображения)

### Стъпки за инсталация

1. **Клонирайте репозиторито**
   ```bash
   git clone https://github.com/MladenNikolow/EKOLidl.git
   cd EKOLidl
   ```

2. **Конфигурирайте connection string**
   
   Създайте файл `appsettings.json` в `Web/EKOLidl.Web/` със следното съдържание:
   ```json
   {
     "ConnectionStrings": {
       "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=EKOLidl;Trusted_Connection=True;MultipleActiveResultSets=true"
     }
   }
   ```

3. **Приложете миграциите на базата данни**
   ```bash
   cd Data/EKOLidl.Data
   dotnet ef database update
   ```

4. **Стартирайте приложението**
   ```bash
   cd ../../Web/EKOLidl.Web
   dotnet run
   ```

5. Отворете браузър на адрес `https://localhost:5001`
